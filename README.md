# BeadGrid

BeadGrid 是一个单文件版的 Aseprite Lua 脚本，用来把当前 Sprite 的当前帧可视图层合并后转换成拼豆图纸。

## 效果图

![BeadGrid Example](./room1-beadgrid.png)

## 当前功能

- 读取当前 Sprite 的当前帧
- 自动合并当前帧的可视图层作为导出源
- 自动按非透明内容裁切图纸范围，不需要手动设置宽高
- 使用内嵌的 `Mard 291` 色卡做最近色映射
- 选择一次导出路径
- 自动导出同名的 PNG 和 SVG
- 默认额外导出一个 `<源文件名>_beadgrid.aseprite` 调色结果文件
- SVG 与 PNG 都使用方格样式
- 每个拼豆格内都带色号标记，例如 `A1`、`A10`
- 图纸边框带坐标轴标号
- 可填写作者名，并展示在导出的 PNG / SVG 中
- 导出页面默认按 `3:4` 比例排版
- 颜色列表显示在图纸下方，不再放在右侧

## 安装

1. 打开 Aseprite。
2. 进入 `File > Scripts > Open Scripts Folder`。
3. 把 [BeadGrid.lua](D:/baguai/绘图/tool/lua/BeadGrid.lua) 放进去。
4. 回到 Aseprite，在 `File > Scripts` 中运行脚本。

## 使用方法

1. 打开一张像素图。
2. 运行脚本。
3. 选择色卡。
4. 填写作者名（可留空）。
5. 选择是否显示网格和图例。
6. 点击 `Export`。
7. 在弹出的保存对话框中选择 PNG 输出路径。

脚本会自动在同一位置额外写出一个同名 SVG 文件。
同时还会默认写出一个 `<源文件名>_beadgrid.aseprite` 文件，用于保留调色后的原图。

脚本会自动：

- 导出 PNG
- 导出 SVG
- 导出调色后的 Aseprite 文件

## 说明

- 当前版本是单文件自包含版，只需要这一个 Lua 脚本。
- 图纸尺寸默认取当前帧可视内容的非透明包围盒。
- 导出的 SVG 不再使用圆点，而是使用方形网格。
- 每个格子默认显示对应色号。
- PNG 与 SVG 的颜色列表会按页面宽度同比例缩放。
- 色彩映射目前使用简单的 RGB 最近色匹配。
- 超大尺寸图纸在 Aseprite Lua 中会明显变慢，建议先用于中小尺寸图稿。
